# CareerCopilot Frontend

AI-powered career platform built with React.

## Quick Start

```bash
npm install
npm start
```

Frontend runs on `http://localhost:3000` and proxies API calls to:
- `/api/v1/*` → FastAPI backend at `http://127.0.0.1:8000`
- Other routes → Express backend at `http://127.0.0.1:5000`

## Features

- 📄 AI Resume Builder & Analyzer
- 🎯 ATS Keyword Score Checker
- 🎙️ Mock Interview Practice
- 💻 Coding Practice (LeetCode-style)
- 💼 AI Job Recommendations
- 🗺️ AI Learning Roadmap Generator
- 📈 Career Analytics Dashboard
- 🤖 Digital Twin AI
- 📡 Technology Trend Radar

## Tech Stack

- React 18 with React Router v6
- Vanilla CSS with design token system
- Monaco Editor for code editing
- Lazy-loaded page components with error boundaries
